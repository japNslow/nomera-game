# ГОСНОМЕРА 3D (Russian License Plates Simulator & Appraisal)

Реалистичный симулятор выпадения и оценки автомобильных номеров РФ по стандарту **ГОСТ Р 50577-93**.

🔗 **Онлайн игра на GitHub Pages**: [https://japnslow.github.io/nomera-game/](https://japnslow.github.io/nomera-game/)

## Особенности игры

- 🇷🇺 **Аутентичный стандарт ГОСТ Р 50577-93**:
  - Настоящий государственный шрифт автономеров
  - Реалистичное тиснение, металлический градиент, пластиковая рамка
  - Болты с позолоченным гербом РФ (Двуглавый орёл)
  - Российский триколор и надпись RUS
- 🎰 **Механический барабан рулетки МРЭО**:
  - Полноценная слотовая анимация выпадения серии, цифр и региона
  - Процедурный синтезатор звуков (Web Audio API) без внешних mp3
  - Одиночный спин (2 500 ₽), Быстрый дроп x5, Авто-крутка до куша
- 💎 **Глубокий экспертный анализ и оценка**:
  - 6 уровней редкости: Обычный ⚪, Необычный 🟢, Редкий 🔵, Эпический 🟣, Легендарный 🟡, Гос-Олимп 🔴
  - База 100+ спецсерий: АМР97 (Правительство/ФСБ), ЕКХ (ФСО), ААА, ООО, МММ, ССС, СКР, ВОР, ХАМ
  - Числовые комбинации: «Три топора» (777), 001, 007 (Бонд), 666, сотки, зеркалки
  - 89 регионов РФ со столичными и региональными коэффициентами
  - Историческая справка и статус в потоке для каждого выпавшего номера
- 🚘 **Виртуальный Гараж и Автопарк**:
  - Примерка номера на культовые автомобили:
    - **Mercedes-Benz S-Class W222** (с трехлучевой звездой и хромом)
    - **Mercedes-Benz G63 AMG "Гелик"**
    - **BMW M5 F90 Competition**
    - **Lada Priora Black Edition** (Опер-стайл)
    - **Rolls-Royce Cullinan VIP**
- 🛠️ **Конструктор своего номера**:
  - Возможность ввести любой номер и получить официальное экспертное заключение
- 🏛️ **Связи в ГАИ (Прокачка)**:
  - Знакомый майор в МРЭО, Спецсклад, Звонок из Кремля, Московская прописка
- 📸 **Экспорт карточки**:
  - Сохранение официального сертификата и фото номера в высоком разрешении (PNG)
